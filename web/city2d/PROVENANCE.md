# Mediterranean city art, experimental

Original generated illustration, October 22, 2026. Internally generated Mediterranean study v3 supplied as style reference for new atlases. No third-party game art or external asset packs used. Source art is generated, not CC0; repository MIT code license does not grant CC0 status or exclusive rights over these images. Rights and historical/style consistency require review before public release. No external license purchased.

Each manifest entry records source atlas filename, crop rectangle and exported WebP SHA256 (fileSha256). Exported WebP files are optimized derivatives. Source atlases are named for traceability; they are not included in this library. Shipyard 3 and tavern 3 use a separate two-sprite source to avoid touching silhouettes in the original atlas. Common isometric camera and upper-left warm light were requested; individual geometry remains illustrative and needs manual review.

The three social house styles are cosmetic only, selected deterministically from the existing plot ID. They do not establish social-class occupancy, population, rent or additional save fields. Levels use the same existing level number. Construction and halted states are existing simulation states, not new rules.

The feature is OFF unless the game URL contains city2d=1. It is not a replacement release. Sources and caveats belong here, not in normal player UI.
