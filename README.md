# hanse-game

Private prototype of a Hanseatic sea-trading game (working title, not final).

- `data/world.json`: 10 cities, sea-lane graph, goods.
- `data/ne_50m_land.geojson`: Natural Earth 50m land (public domain, naturalearthdata.com).
- `src/sim/`: simulation core (market model, routes).
- `tools/`: geometry helpers and SVG map renderer.
- `test/`: `node --test test/world.test.mjs`

Original code and data. No assets or data copied from other games. Not published. Licence undecided (all rights reserved for now).
