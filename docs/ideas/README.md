# Ideas from other games (not approved)

Each file is one idea or a small group, taken from manuals, guides and wikis (text only, no screenshots). Every idea says what the source does, what our own version would be, what it costs, and what could go wrong. Nothing here is copied: no art, text, names, data or code. Status of all ideas: proposed, not approved; the owner picks what enters a milestone. Rules that apply to all: `docs/design/content-stance.md` and `docs/design/asset-licences.md`.
