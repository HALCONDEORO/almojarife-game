# Calibration policy guard, inactive pure module

This validator is NOT a claim that a game policy is historically correct. It rejects unresolved unit/provenance gaps before a future calibration could be connected: every good/class requires explicit daily physical quantity and evidence type; non-assumption values require source URL, period and source population; demographic coefficient and cargo scale are separate explicit values. Bread/grain, cloth-length/mass and food-preparation conversions cannot be defaulted.

A named gameplay assumption can be represented as such. It does not become a source reconstruction. A source about an adult worker or an elite household emits an extrapolation warning when used as a full population rate. Unknown chickpea preparation blocks energy/cargo integration. Different dry/cooked states need yield and provenance. This is input validation, not permission to activate or proof that cited sources support a claim.

Pure module only, not imported by market/UI.6/6 tests. No gameplay effects, penalties, telemetry visibility, numeric gates or balance changes. Research routing: A model/integration; D food data; BO+Ingresos exact-SHA reviews before Estudio merge. Missing yields remain unresolved rather than being supplied by this document.
