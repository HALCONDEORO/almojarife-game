# Asset licence policy and credits ledger (M0, issue #9)

Allowed sources, in order of preference: our own work (CC BY 4.0 for art, MIT for code), CC0, CC BY, OFL for fonts. Not allowed: CC BY-NC, CC BY-ND, GPL art or code copied into the project, anything with unclear terms, anything taken from other games, AI output with unclear rights.

Rules:
1. Every asset (image, sound, font, data file) has a row in CREDITS.md before it is merged: file, author, source link, licence, date added.
2. Only assets with a row can be merged. A pull request check lists new files under `assets/` and `data/` without a row.
3. Fonts must cover Spanish characters (á é í ó ú ñ ü ¿ ¡).
4. Third-party map data (Natural Earth, public domain) is downloaded by script at a pinned commit, not copied.
5. No real trademarks, logos or real people's likenesses.
6. When in doubt, leave it out and open an issue.
