# Start and campaign proposal

Isolated `web/mock/start.html`, not linked from the real game. Spanish review mock first, ES+EN required in implementation.

Flow: Continue, Campaigns, Free game, Settings. Campaign selection leads to character/house setup, chosen start port and the city, then a guided objective. Proposed chapters: learn a profitable voyage and read its report; expand with a route and two warehouses; survive changing markets and competition. Names, goals, time limits, unlocks and free-game victory rules require review and calibration. They are not existing implemented modes.

Continue would show save context, not immediately reset it. Import/export belong in Settings, not beside the main Start action. Current mock does not read/write local saves or start actual games. The SVG illustrations are original, not third-party game assets.

Desktop 1440 and phone-width 390 screenshots visually inspected. Cards stack vertically on mobile. Buttons change local mock views only. Campaign detail/free view/return tested in headless Chrome. No physical phone check. Mock should be shown to the project owner before production changes.
